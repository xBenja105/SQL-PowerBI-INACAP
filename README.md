# Proyecto: Análisis de Datos con SQL Server + Power BI  
_(Trabajo académico INACAP)_

## 📌 Descripción  
Este proyecto muestra una implementación de un mini-datawarehouse para una base de datos ficticia de clientes, empleados, transacciones u otras entidades — usando SQL Server.  
Desde esa base de datos se generaron scripts de creación y carga de datos, y luego se construyó un informe visual usando Power BI, con limpieza y transformación mediante Power Query.  

## 📁 Estructura del repositorio

| Carpeta / Archivo | Contenido / Propósito |
|------------------|------------------------|
| `db/` | Scripts SQL para crear la base de datos + poblarla con datos. Permite reconstruir la base de datos completa. |
| `AquaSafe.pbix` | Informe Power BI con visualizaciones e indicadores. |
| `AquaSafe.pdf` | Versión exportada del informe (para quienes no tienen Power BI). |
| `InformeES2_Arriagada_Castro.docx` | Documento del proyecto entregado en la universidad (contexto, objetivos, análisis, conclusiones). |
| `README.md` | Esta documentación general del proyecto. |
